# 🔮 Magic 8-Ball

> Ask a yes-or-no question. Shake the ball. Get your destiny (probably).

A single-file, glossy 3D Magic 8-Ball built with plain HTML, CSS, and JavaScript. No dependencies, no build step — open it and ask away.

## ✨ Features

- **Classic shake animation** — tap the ball (or the button) for a wiggle + fade-in reveal
- **25 fortunes** — all 20 classic 8-ball answers plus 5 playful bonus ones
- **Glossy 3D ball** — layered radial gradients for a realistic glassy look
- **Fortune counter** — tracks how many answers you've received
- **Fully responsive** — works on phones and desktops
- **100% offline** — one `index.html` file, nothing to install

## 🚀 Run it in 30 seconds

1. Download or clone this repo
2. Open `index.html` in any browser
3. Think of a yes-or-no question, click the ball, and read your fortune

That's it. No server, no npm, no setup.

## 🧠 What was practiced

- CSS radial gradients + `box-shadow` for 3D effects
- CSS keyframe animations (`@keyframes shake`) triggered from JS
- DOM event listeners and class toggling for UI state
- `setTimeout` to sequence animation → reveal
- Arrays, `Math.random()`, and template literals
